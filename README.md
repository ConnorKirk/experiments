# Experiments

Browser-based tools and demos. Everything runs client-side — no backend required.

## Projects

| Project | Description |
|---------|-------------|
| [CloudFormation Tools](cfn-tools/) | Format, convert, validate, diff, and inspect CloudFormation templates — powered by [rain](https://github.com/aws-cloudformation/rain) compiled to WebAssembly |
| [System Architecture Simulator](system-simulator/) | Build an architecture on a canvas and watch simulated traffic flow through it to find where the design breaks |
